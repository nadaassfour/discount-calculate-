# 💸 Discount Calculator (Strategy Pattern)

A standalone PHP application that calculates cart discounts 
using the Strategy Design Pattern.

---

## 📖 Project Overview

This project demonstrates:

- Object-Oriented Programming (OOP)
- Interfaces
- Strategy Pattern
- Clean code structure

The system allows applying different discount strategies 
without modifying existing code.

---

## 🧠 Design Pattern Used

Strategy Pattern

Each discount type implements the `Discount` interface.

Examples:

- PercentageDiscount
- FixedDiscount

---

## 🛠 Technologies Used

- PHP 8+
- OOP Principles
- Git & GitHub

---

## ▶️ How to Run

1. Clone the repository:

git clone https://github.com/nadaassfour/discount-calculate-.git


2. Open the project folder

3. Run:

php index.php
